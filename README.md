# BlinkAndRelax

Extensión Chromium en preparación para recordar descansos visuales mediante notificaciones y un pequeño panel (*popup*).

El proyecto contiene la infraestructura de Spec Kit y una guía para desarrollar la primera versión con HTML, CSS y JavaScript. Todavía no hay una extensión implementada; la constitución y la primera especificación están pendientes.

## Nombre del proyecto

El **18 de octubre de 2026** se decidió sustituir **SightPause** por **BlinkAndRelax**.

| Uso | Nombre |
| --- | --- |
| Marca y nombre visible | **BlinkAndRelax** |
| Repositorio e identificadores técnicos nuevos | `blinkandrelax` |
| Repositorio de GitHub | [rublaman/blinkandrelax](https://github.com/rublaman/blinkandrelax) |
| Carpeta local actual | `C:\dev\sightpause` |

La carpeta local conserva su nombre para mantener las rutas del proyecto abierto. Los documentos de investigación en `docs/research/` conservan los nombres evaluados, las fuentes y las recomendaciones de cada revisión. La elección de BlinkAndRelax sustituye las menciones históricas a una elección pendiente; no implica que se hayan realizado las pruebas con participantes ni la revisión registral descritas en esos documentos.
