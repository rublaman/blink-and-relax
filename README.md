# BlinkAndRelax

> **WIP — Work in progress.** The project is under development, and the extension is not yet ready to use.

A planned Chromium extension that reminds you to take eye breaks through notifications and a small popup.

The project contains the Spec Kit infrastructure and a guide to building the first version with HTML, CSS, and JavaScript. The extension has not been implemented yet; the project constitution and first feature specification are still pending.
